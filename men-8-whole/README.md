# men-8-whole — Whole-gender experiment (men's shoes, size 8)

The **whole-gender baseline** for men: all men's size-8 listings in one model, embeddings
trained on the entire gender. This is one of the two original runs (the other is
[`women-8-whole`](../women-8-whole)) and the reference point for every subcategory split.

See the project report [`../summary/SUMMARY.md`](../summary/SUMMARY.md) and the root
[`../README.md`](../README.md) for the full context and methodology.

## Headline result

| | rank-elasticity | **demand elasticity** (ϑ-converted) | 90% sig | train ASINs |
|---|--:|--:|:--:|--:|
| men-8 (text+image, main spec) | −0.101 | **−0.169** | yes | 1,029 |

Stable across all five control specifications. Demand elasticity = rank-elasticity × 1/0.6
(see root README §4).

## What this folder is

- **Design:** whole-gender. Embeddings are trained (fully fine-tuned) on all men's size-8
  products, not per-subcategory.
- **Data:** ~2,061 clean ASINs, stratified 50/50 train/val split (1,029 / 1,032), zero ASIN
  overlap, original split seed preserved across the whole project.

## Pipeline — run in order

**Phase 0–1, data + embeddings (`data_preparation/`):**
1. `00_part1_data_preparation.ipynb` — clean, filter to men's size 8, forward-fill, build
   subcategory aggregation, stratified 50/50 train/val split.
2. `00_part2_download_images.ipynb` — download one JPEG per ASIN (not committed; see root §6).
3. `00_part3a–3d_train_*.ipynb` — train the four embedding variants on GPU:
   txt+img/lag1, txt+img/time-independent, txt/lag1, txt/time-independent. Each writes 6
   prediction zips → `data/predictions/`.
4. `00_part4_verify.ipynb` — verify the 24 prediction zips and write `utils/paths_config.yaml`.
5. `00_part5_create_image_parquet.ipynb` — pack images into parquet shards for HuggingFace
   datasets (not committed).

**Phase 2–3, analysis (`code/`):**
6. `01_1_create_dataset_txt_img.ipynb` / `01_2_create_dataset_txt.ipynb` — join embeddings,
   run PCA (5 comps), KMeans (k=5), nearest-neighbor competitor prices, first differences →
   `data/dataset_txt_only_{False,True}_embeddings_True_{train,val}.zip`.
7. `02_cluster_centroid_products*.ipynb` — cluster sanity-check collages → `output/02_*`.
8. `03_1/03_2_predictive_performance_*.ipynb` — R² of feature sets for prediction.
9. `04_evaluation.ipynb` — **the DoubleML elasticity estimates.** Runs both embedding variants
   (text+image and text-only) and all five control specs, reports ATE + CATE, the χ²
   heterogeneity test, and both raw rank and ϑ-converted demand elasticities → `output/04_*`.

## Outputs

- `data/` — analysis datasets and the embedding `predictions/` (committed).
- `output/04_evaluation*/` — the elasticity tables and forest plots that
  [`../summary/00_summary.ipynb`](../summary/00_summary.ipynb) aggregates.
- `data/images/` — product JPEGs, **not committed** (regenerated by `00_part2`).
